# AGENTS.md

Перед работой прочитайте README и релевантные документы репозитория.

- Новые документы, рабочие записи и отчёты пишите на русском.
- GitHub Projects — единственный рабочий трекер. Исторические Linear, AppFlowy, Notion и Todoist не обновляйте.
- Используйте только подтверждённый Project и существующие issue; не создавайте дубли и не придумывайте Project URL.
- Идеи и гипотезы фиксируйте с явным статусом. Существенные решения сохраняйте с датой, статусом `предложено` / `принято` / `отклонено`, причиной и источником.
- Обновляйте затронутую документацию в том же смысловом изменении.
- Проверяйте фактическую базовую ветку, открытые PR, CI и правила выпуска.
- Документационные изменения доставляйте через отдельную безопасную ветку и PR.
- Документационный агент может самостоятельно merge только проверенные docs-only изменения по прямому решению Романа от 08.10.2026.
- Кодовые и смешанные PR требуют отдельного разрешения.
- Не выполняйте auto-merge или deploy в docs-задаче.
- Не меняйте код, зависимости, workflow, права или production-настройки ради документационной задачи.
- Не публикуйте секреты, персональные данные и приватные рабочие материалы.

- Перед запуском Telegram runtime проверяйте allowlist trusted chat IDs и допустимые workspaces.
- Документационная задача не разрешает отправлять сообщения, запускать coder против внешнего workspace или удалять память.
