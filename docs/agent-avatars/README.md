# Agent Avatars

Единый набор локальных SVG-аватарок для команды супербота.

- Рэй: `docs/agent-avatars/ray.svg`
- Мира: `docs/agent-avatars/mira.svg`
- Платон: `docs/agent-avatars/platon.svg`
- Коди: `docs/agent-avatars/cody.svg`
- Вера: `docs/agent-avatars/vera.svg`
- Видо: `docs/agent-avatars/vido.svg`

Ограничение Telegram: у одного бота одна реальная аватарка. Эти файлы нужны для web-панели, карточек команды, документации и будущих профилей агентов.
